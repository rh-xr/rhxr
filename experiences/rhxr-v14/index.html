Que vérifier dans le Quest ?

  1. Ouvrir le bureau V14 dans Quest Browser, entrer en VR et confirmer que les trois meubles GLB sont visibles.
  2. Examiner les murs, l'éclairage, les matériaux, les fenêtres simulées et le logo RH·XR sans anomalies visibles.
  3. Tester manette gauche (déplacement), manette droite (rotation par 45°) et marche réelle.
  4. Revenir à la page de diagnostic pour observer les FPS estimées, les draw calls et les triangles dans le casque.
  5. Quitter la VR puis utiliser « Exporter diagnostic local » dans la vue navigateur afin de conserver un rapport JSON anonyme.

Important : les FPS sont estimées à partir des intervalles entre rappels d'animation. Elles ne mesurent pas le temps GPU/CPU. Une validation approfondie nécessite un outil de performance Quest tel que OVR Metrics.
