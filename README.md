# RH·XR — Human Resources Extended Reality

Plateforme indépendante de formation immersive et de développement des compétences RH par réalité augmentée (RA), réalité virtuelle (RV) et intelligence artificielle.

> **Statut :** initialisation du dépôt. Les prototypes sont développés et validés dans des branches de travail avant intégration dans `main`.

## Gouvernance

- Aucun jeu de données RH réel dans le dépôt.
- Pas de décisions RH automatisées à partir des scores pédagogiques.
- Développement progressif avec tests et Pull Requests.

Lot 0 : portail de démonstration, simulation formative S02 « Gérer un désaccord professionnel », Studio exploratoire et salle 3D expérimentale.
